Gallery photos
==============

Add or remove .avif, .gif, .jpg, .jpeg, .png, or .webp image files in this
folder. The GitHub Pages build discovers them and generates the gallery list;
you don't need to edit the slide markup in index.html. Push your changes to
the deployment branch to publish new photos.

For easier GitHub uploads and faster page loads, resize large photos to about
1920 pixels on the longest side and compress them before adding them here.
The gallery fits each whole photo inside its 16:9 frame.

Locally, `npm start` serves the /api/gallery-images endpoint. Descriptive
filenames are used to generate image alt text.
